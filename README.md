# Бит и Случай

Интерактивная книга для подготовки к сессии. Два тома:

- **Случай** — теория вероятностей и математическая статистика, 11 глав по «Руководству к решению задач» В. Е. Гмурмана.
- **Бит** — вычислительные машины и системы, 10 глав по практической работе №1, лабораторным 1–4 и книге А. Зубкова «Assembler для DOS, Windows и Unix».

В каждой главе: теория и формулы, вопрос «предскажи», интерактивный рисунок, разбор под клапаном, задача на штамп и ещё три задачи с проверкой ответа. Есть тренажёр из 10 случайных вопросов и отсчёт до экзамена.

## Как открыть

Дважды щёлкни **`Бит и Случай.html`**. Интернет и сервер не нужны: шрифты и скрипты встроены в этот файл.

С GitHub: зелёная кнопка **Code → Download ZIP**, распаковать, открыть `Бит и Случай.html`.

Прогресс (штампы, решённые задачи, дата экзамена) хранится в браузере, на котором открыт файл. В другом браузере он будет свой.

## Как поправить и пересобрать

Исходники лежат в `book/`:

| Файл | Что внутри |
|---|---|
| `book/index.html` | оформление, движок книги, обложка, тренажёр |
| `book/tv.js` | главы «Случая» и задачи из Гмурмана |
| `book/vms.js` | главы «Бита» и задачи по практической и лабам |
| `fonts/fonts.css` | шрифты Alegreya, Literata, Caveat, JetBrains Mono (кириллица и латиница) |

После правок собери офлайн-файл заново (нужен [Node.js](https://nodejs.org)):

```bash
node build-offline.js
```

## Источники

Условия задач процитированы из учебника В. Е. Гмурмана и методических материалов курса ВМиС для учебных целей. Ответы к задачам Гмурмана сверены с разделом «Ответы» книги, ответы к практической №1 и лабам посчитаны отдельно. Шрифты распространяются по лицензии SIL Open Font License.
